# Museum API — WEB322 Capstone

**WEB322 capstone** — Seneca College, 2023.

Full-stack museum artwork browser with a Next.js front end and authenticated API integration.

## Features

- Browse and search artwork records
- User authentication and protected routes
- Responsive UI with Chakra UI / Material UI

## Stack

Next.js · React · Node.js API · JWT

## Run locally

```bash
npm install
npm run dev
```

Set API base URL and auth keys in environment variables.
